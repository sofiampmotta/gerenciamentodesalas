# Gerenciamento de Salas — POLI-UPE

## Sobre o projeto

O Gerenciamento de Salas é um projeto acadêmico desenvolvido na disciplina de Programação Imperativa da POLI-UPE.

O objetivo é desenvolver um software em linguagem C para auxiliar no controle e na alocação de salas e laboratórios da instituição, tornando o processo mais organizado e eficiente.

Atualmente, esse controle é realizado por meio de planilhas eletrônicas. A proposta é desenvolver uma solução local que facilite o gerenciamento dos ambientes, a consulta de disponibilidades e a prevenção de conflitos de alocação.

## Objetivos

- Organizar o cadastro dos ambientes.
- Facilitar o gerenciamento das alocações.
- Permitir consultas sobre ocupação e disponibilidade.
- Armazenar os dados localmente.
- Reduzir erros e tornar o processo de gestão mais eficiente.

## Tecnologias

- Linguagem C.
- Arquivos locais para persistência de dados.
- Biblioteca gráfica a definir após avaliação técnica.
